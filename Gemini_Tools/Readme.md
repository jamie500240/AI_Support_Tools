# Gemini_Tools 使用方法與創作原因
## 功能：擴充 Gemini 功能。
> 雖然有更方便的擴充工具，如：Gemini Voyager、Superpower for Gemini，但因為萬用擴充工具所需的權限太多，故寫一個陽春版本使用。
## 使用方式：
- 1. 創造新書簽（空白書籤），將書籤任意命名為所需的名稱。
- 2. 把需要的功能的 Code 貼到書籤列的網址。
- 3. 每次需要檢視時，點一下書籤即可使用。 
## 目前功能：
- 1. Gemini_Sidebar 專門在 Gemini 上創造一個跟 GPT 一樣的側邊欄，管理對話紀錄。
- 2. 下載對話紀錄為 md 檔案 (附加圖片)。 
## 資料夾整理功能：目前已知技術受限，應該暫時無法實作。
