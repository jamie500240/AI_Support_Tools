# Gemini_Tools 使用方法

## 功能

擴充 Gemini 功能，提供輕量化且低權限需求的個人化工具。

> 雖然已有較完整的擴充工具，如 Gemini Voyager、Superpower for Gemini，
> 但考量萬用型擴充工具通常需要較高權限，因此開發此陽春版本，
> 以書籤小工具方式提供所需功能。
>
> 本專案為獨立開發之輕量替代方案，與上述工具無關聯，功能範疇亦不相同。

## 使用方式

### 1. 建立新的瀏覽器書籤（空白書籤）。
### 2. 將需要的 JavaScript 程式碼貼入書籤網址欄。
### 3. 使用 Gemini 時，點擊對應書籤即可執行功能（側邊欄｜下載）。

> **注意：**
> - 側邊欄跟可匯出頁面**無法永久同步**最新狀態。側邊欄工具會自動監看頁面內容變化，
>   偵測到新訊息或新標題時自動重建導航列，不需重新點擊；但仍建議頁面跳轉或重新整理後
>   重新點擊書籤初始化一次。
> - 要匯出的資訊時，需要**手動捲動整個對話**，比較能完整匯出。下載工具會嘗試自動偵測
>   「是否從對話最上方開始擷取」，若偵測到上方可能還有內容未載入，會於檔案內與畫面上
>   跳出提醒；此偵測為盡力而為，非絕對保證，仍建議自行確認匯出範圍。
> - 匯出的 md 檔開頭會註明本次實際擷取的訊息則數與範圍（例如「第 1 則至第 N 則」），
>   此為依畫面實際擷取順序計算，**不代表**必然等於完整對話總則數，請自行核對。
> - 下載完成後，若對話持續有新內容，下載工具會跳出「內容已更新，如需匯出最新版本請
>   重新點擊」提示，但**不會自動重新下載**，避免產生不完整或重複的檔案。
> - 閱讀匯出的 MD 檔案，可使用 Visual Studio Code（Shift + Ctrl + V 預覽）或其他 Markdown 編輯器。
> - ⚠️ **隱私提醒**：匯出功能會將整個 AI 對話內容（含文字、圖片）完整下載至本機檔案，不會過濾任何內容。下載後請務必自行檢查檔案中是否包含個人隱私資訊、密碼、金鑰等敏感內容，再決定是否分享或上傳該檔案。
> - ⚠️ **檔案匯出限制**：本工具僅能擷取對話中的文字與程式碼區塊，以及以 `<img>` 標籤呈現的圖片。**使用者上傳的檔案**（如 圖片、PDF、Word、Excel）**與 AI 生成的檔案**（如 Claude Artifacts、ChatGPT Canvas 產出的實際檔案），皆無法透過此工具下載，請另行手動保存。

## 目前功能

| 名稱 | 功能 | 目前可用 | 限制 | 推薦 |
|---|---|---|---|---|
| Gemini_Sidebar | 在 Gemini 建立類似 GPT 側邊欄的對話導航工具，用於管理與定位長對話 | Gemini | 其他 AI 失敗率高 | |
| UserSpeak_Sidebar | 抓出使用者的對話框 | Claude、Grok | 受到底層代碼的影響，是抓 USER 的特徵，有一定的不穩定性 | |
| H1-H3_Sidebar | 抓出 H1-H3 對話框，並顯示預覽文字 | 只要是只用 H1-H3 的頁面都能用（適用 AI：Claude、Grok、Gemini、Copilot、Perplexity） | 要有寫 H1-H3 標題的頁面才有用 | |
| Title_Sidebar | 抓出 H1-H4 對話框與粗體標題，並顯示預覽文字 | 只要是只用 H1-H4 和粗體字的頁面都能用（適用 AI：Claude、GPT、Gemini、Grok、Copilot、Perplexity） | 純圖片或是純文字，連粗體都沒有的網頁無法使用 | ★ |
| Gemini_MdDownloader | 將 Gemini 對話匯出為 Markdown 檔案，包含圖片與程式碼格式；具備開頭完整性偵測與新內容提醒 | 只針對 Gemini 研發 | 下載圖片時，有一定機率無法載入 | |
| AI_MdDownloader | 匯出 AI 的對話為 Markdown 檔案，包含圖片與程式碼格式；具備開頭完整性偵測與新內容提醒 | Claude、GPT、Gemini、Grok、Copilot、Perplexity | 必須自己捲動頁面，捲動多少頁面，就能下載多少資料 | ★ |

## 推薦使用

如果只想安裝兩個功能：

### 1. Title_Sidebar ★
適合閱讀長篇 AI 回答，快速跳轉章節。

### 2. AI_MdDownloader ★
適合保存 AI 對話，建立自己的 Markdown 知識庫。

## 已知限制

### 資料夾整理功能

受限於瀏覽器安全機制，JavaScript 無法直接存取使用者本機檔案系統。

基於權限最小化與資料控制考量，不使用額外 API 或第三方工具協助，因此暫不規劃此功能。

### 檔案型內容無法匯出

見上方「使用方式」中的檔案匯出限制說明。此為 DOM 擷取機制的結構性限制，非個別平台的暫時性問題，短期內無修復規劃。

### 完整性偵測非絕對保證

多數平台採用虛擬滾動（Virtual Scrolling），畫面外的舊訊息 DOM 節點可能被直接移除，
而非僅僅隱藏。下載工具的「開頭完整性偵測」僅能透過捲軸位置間接判斷，屬於盡力而為的
輔助提醒，無法百分之百保證偵測結果正確，仍建議使用者於匯出前自行手動捲動確認。
